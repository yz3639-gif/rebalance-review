# Production Worker browser performance

Run `BROWSER_PERF_BASE_URL=http://127.0.0.1:8787 node oracle/browser-performance.mjs` against an already-built, already-running preview at `http://127.0.0.1:8787`. Override `BROWSER_PERF_BASE_URL` if an isolated static server is preferable. The harness never builds, changes app code, or starts/stops the existing server. An equivalent optional Vitest entry is `RUN_BROWSER_ENGINE_BENCHMARK=1 npm test -- tests/engine-browser.performance.test.ts`.

The harness loads the existing production page and fetches its exact hashed Worker asset. It checks fetched bytes against the file SHA-256, executes the same bundled code from a Blob module Worker, and allows only requests to the chosen localhost origin. Three browser engines run sequentially, with three warmups and thirty measured calculations apiece. Timings include input structured cloning, computation, output cloning and the message roundtrip. An additional thirty measurements include fresh Worker construction from the preloaded asset, reflecting the app's per-review Worker lifecycle without measuring network transfer.

Inputs are deterministic synthetic data for **50 catalog ETFs**, with 5,000 supplied daily observations. The product applies its five-calendar-year historical cap and calculates 126/252/504-session risk, both portfolios' history, cost scenarios and the delay scenario. The separate Node kernel benchmark also covers fifty series but is a different measurement. Neither is full application latency: UI chart paint, remote transfer, mobile hardware, concurrent user load and real-person usability are excluded.

Running the harness creates `oracle/browser-performance-v1.2.json` with machine memory/CPU, browser versions, build hashes, every timing observation, p95 and the returned review's actual common window. This machine-specific output is not shipped as a passing record in the public source package. Local runs may share machine resources with other engineering checks. Evaluate the two-second criterion against the actual recorded headless desktop-browser environment; it is not a universal performance guarantee.
